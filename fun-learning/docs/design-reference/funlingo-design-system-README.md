# Funlingo Design System

One source of truth, no older versions included.

- `Funlingo-Design-System.html` - the full design system. Open in a browser.
  Colour, type, spacing, radius, shadows, motion, icons, components, voice rules.
- `tokens/tokens.css` - the CSS variables, copied verbatim from the HTML above.
- `tokens/tokens.json` - the same values as JSON (brand, dark + light theme, typography,
  spacing, radius, shadow, motion).
- `brand/` - logo, wordmark, lockup, mark, app icons, favicon, splash.

Brand: purple #BC22D6 -> deep magenta #9A1C8E -> pink #E0319E. Font: Poppins.
Dark theme is the default (bg #0E0816); light theme bg #FBF4FF.

Earlier palettes (#841167 / #b218d1, Cinema Noir) are superseded and intentionally left out.
