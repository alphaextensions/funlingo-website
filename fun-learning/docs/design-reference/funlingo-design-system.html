How decisions get made

Three rules settle
most design questions.

Funlingo is a consumer product, not SaaS. The feeling is a night in with a good show — warm, playful, effortless. Never studious, never enterprise.

1

Show, don't tell

Where a competitor writes a feature bullet, Funlingo builds a thing you can touch — the hover-a-word player, the guess-the-meaning game. Both are live further down this page.

2

Free is the loudest message

It appears in the hero badge, the comparison table, the CTA and the FAQ — never buried. The word free is allowed to repeat; it is the positioning.

3

Fun with restraint

Playful motion and colour, but type stays legible and layouts stay calm. No confetti for its own sake. Nothing bounces, nothing springs.

Tight tracking is not optional

Headlines carry letter-spacing:-.02em. Without it, display type at 82px looks loose and cheap. Line-height is 1.0–1.04 on headlines, 1.55–1.6 on body.

CJK has no inter-word space

The hero is composed as hero_pre + hero_accent, with the trailing space baked into hero_pre for spaced scripts and omitted for zh-CN / zh-TW / ja.

Breakpoints

860px — layout collapse: hero goes single column, nav links hide, every multi-column grid becomes 1fr, floating bubbles disappear.

700px — chrome compaction: 34px logo, 38px controls, section padding 104 → 56, player screen 372 → 270, subtitles 29 → 21.

560px — tightest: the comparison table scrolls horizontally rather than crushing.

Shadow is coloured, never neutral grey

Large blur, large negative spread, brand-tinted — it reads as glow, not drop shadow. Cards have no shadow at rest; the 1px border does the separating. Shadow is reserved for things that float.

Depth comes from four things only

There is no photography and no illustration anywhere on the site.

Ambient glow orbs

Radial circles at 20–24% opacity, bled off the edge, always inside an overflow:hidden parent, always pointer-events:none. Two per section, maximum.

Alternating grounds

--bg / --bg2 with 1px --border rules between them.

Backdrop blur, twice

The sticky nav at blur(16px) over 78% opacity, and the player's platform chip at blur(6px). Nowhere else.

A protection gradient

150px of linear-gradient(to top, rgba(8,4,16,.9), transparent) inside the player so subtitles stay legible over any frame.

Marquees start paused

They only run when the section scrolls into view. Otherwise a visitor arriving at the testimonials sees content that has already scrolled past — the language-prioritised reviews would be wasted and an empty gap feels broken. Rows are forced dir="ltr" even in RTL so cards don't gap. prefers-reduced-motion cancels the hover lift.

Iconography

No icon font.
No icon library.

Every glyph is hand-drawn inline SVG on a 24×24 grid, coloured with currentColor so it inherits theme colour for free. Stroke weights are deliberate: 1.6 hairline, 2 default, 2.4 chevrons, 3 for the checkmark inside a gradient circle. Two glyphs are solid fills — bookmark and speaker.

The complete set. If a design needs a glyph outside it, draw it in the same idiom rather than importing an icon pack.

Flags are geometry, never emoji

Emoji flags render inconsistently across platforms. Funlingo draws rectangles on a 26×19 rounded box with a 1px shadow.

The Chrome wheel

A conic-gradient circle with two nested inset circles. It must keep flex-shrink:0; flex-grow:0; aspect-ratio:1, or narrow buttons squeeze it into an oval.

Unicode, sparingly

Used as icons where a drawn glyph would be overkill. No emoji in UI chrome — only in playful moments, like the game result.

★ ratings ✕ absent → saved + FAQ

Platform marks — real brand logos, 9px chips

34px chip, 9px radius, white background (navy for Disney+), image capped at 24px so it never touches the chip edge. Netflix gets #141414.

The logo

A gradient play-triangle containing an F, followed by the Funlingo wordmark in the same gradient. 848×362, transparent. 44–56px tall in the nav, 40–48px in the footer. Never recolour it; never place it on a mid-tone that swallows the gradient.

Why these two, and nothing else

The player and the game are the product's whole argument. A competitor writes "instant word meanings" as a bullet; Funlingo hands you a word and lets you hover it. Both localise fully — the helper line, the meanings and every game option switch to the visitor's language.

Correct-answer green is the one non-brand hue

#16B57F exists because a right answer must not read as pink-ish ambiguity. It appears nowhere else in the system.

The popup is white in both themes

It is a dictionary card floating over a dark player, not a themed surface. Toggle the theme and watch it stay put.

Content fundamentals

Funlingo talks the way
a friend recommends a show.

Second person, informal
In every language — tú / du / ты. Short declarative sentences.
Sentence case everywhere
Headlines, buttons, card titles. The only uppercase is the 13px eyebrow, the 11–12px status tags (LEARNING ES, NETFLIX) and footer column headers. Never title case a headline.
Headlines are two beats
Almost every H2 is two short sentences with a hard line break. The first beat sets the scene, the second lands the claim.

"Watch what you love. / Pick up the language."
"Everything they charge for. / Yours for $0."
"Turn tonight's episode / into your next lesson."
One accent word
Hero headlines put exactly one word in the gradient — "Learn while you watch.", "Where Funlingo is headed." Never two.
Answer first
FAQ answers open with the answer word: "Yes — completely." · "Nope." · "No." Then two sentences of detail, then stop.
Say the price
"Free forever", "It's Free", "Yours for $0", "$0 forever". The word free is allowed to repeat; it is the positioning.
Real proof only
4.8★ Chrome Web Store, 8 platforms, 100+ languages, $0, and one cited study (Montero Perez et al.; Krashen's input hypothesis). One strong cited stat beats five invented ones. Never ship a number without its source.
Translate the idiom
Never the words. 追剧，就是新的学习方式 — "binge-watching is the new studying" — not a literal rendering of the English.
Emoji
None in UI chrome. Sparing in playful moments only — the game result 🎉. The ✓ and ✕ in the comparison table are a stroked SVG and a Unicode glyph, not emoji. ★ is used for ratings.

Where the values came from

The production build of getfunlingo.com was read directly: the rendered DOM (every component on the site is inline-styled, so exact paddings, radii, font sizes and shadows come from the real markup), the compiled stylesheet (source of the :root token block and all @keyframes) and the page chunk (source of the word popup, the game states and the flag SVGs). A brand brief from the project owner was cross-checked against the live CSS — every value matched.

Known gaps

  • No Figma file or repository was provided. Component names here are the system's own, not your codebase's.
  • Internationalisation is documented, not implemented. The real site ships 21 locales, browser auto-detection, a localStorage-persisted globe switcher, regional fallback (en-GB → en, pt-PT → pt-BR, zh-TW → zh-CN) and dir="rtl" for Arabic. The UI kit is English-only. Use text-align:start and margin-inline-start — never left/right — so components mirror automatically.
  • Testimonial avatars are omitted. The live site uses pravatar placeholders, which are not brand assets.
  • The extension's own chrome — options page, browser-action popup — was not available and is not represented. The in-player UI is, as components.
