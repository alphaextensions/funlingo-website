# Logos

The Funlingo mark is a rounded play-triangle holding a white *F*, filled with a vertical gradient from purple (#BC22D6) at the top to deep plum at the bottom. The wordmark is a heavy italic set in the same gradient.

- **funlingo-lockup.png** (2420×880): mark plus wordmark. The default in navs and footers, 44–56px tall in the nav, 40–48px in the footer.
- **funlingo-wordmark.png** (1598×450): the name alone, for places where the mark already appears nearby.
- **funlingo-mark.png** (384×384): the play-triangle alone. App icon, favicon, avatar, extension icon, loading states.

Rules: never recolour, outline or re-draw the mark; never place it on a mid-tone purple or pink that swallows the gradient (use `bg`, `bg2`, `surface` or white); keep clear space of at least the height of the *F* around it. All files are transparent PNGs from the `funlingo-v2` project assets.
